## 一、视频在讲什么

UP 主用**自建的数据仪表盘**（他自己也是用 AI 编程工具做的，视频 04:00 处有画面）统计了「几十个机型、近万条价格记录」，还原 2025-08 ~ 2026-09 一年间笔记本的涨价曲线。结论：

| 结论 | 幅度 |
| --- | --- |
| 主流价位（5060 游戏本 / 5000 元轻薄本） | 普遍 **+50%** 以上 |
| 2026 款小改款与 2025 款连起来看 | 涨幅可超 **+80%** |
| 高端本（5070Ti / 5080）反而更抗涨 | **+40%** 左右 |
| Mac 全场最稳（6/25 官方一次性 +1500） | **+20~25%** |
| MacBook Pro M4 Max（统一国补口径后） | 全场**唯一降价** |

核心难点不在画图，在**数据口径**：京东 2026-05-10 前后标价规则变了（页面价从「不含国补」转成「已减国补」），他花了整段视频讲怎么把不同口径的价格洗到同一条曲线上。

## 二、他的数据方法论（值得抄的思路）

1. **单一数据源**：只用慢慢买记录的京东自营页面价，最早可回溯到 2025-08。
2. **统一国补口径**：所有价格折算成「国补后到手价」。例：2025-11-02 记录 5599.2 元，逆算 ÷0.8 = 6999 正好是整数标价 → 判定为已含国补的有效价。
3. **整数价渗透率**：用「整数标价占比」衡量当时页面价含不含国补——2025 年 8-9 月占比 95%+（不含），2026-05 转向后掉到 24%（含）。
4. **邻近推定 ±8%**：有效价前后 15 天内的记录，若「原价」或「×0.8 后」恰好只有一个落在参照价 ±8% 内，则采信为推定价；推定点不再作为新参照。
5. **爆料凭证补充**：日期/SKU/配置/价格都能对应上历史好价爆料的，标记为可信点（紫色）。
6. **无货定格**：无货/下架机型最后价格连续 15 天不变后转灰，提示「买不到了」。

## 三、图表设计语言拆解（他做得好的 12 个细节）

### 主图：单机型价格走势阶梯图

| # | 设计元素 | 作用 |
| --- | --- | --- |
| 1 | **阶梯折线（step line）** | 价格是离散事件：每次调价维持到下一次。阶梯线比平滑曲线诚实，能读出「某价位维持了多久」 |
| 2 | **颜色=数据来源** | 蓝实心圆=直接采用记录价；橙三角=补算国补后；紫锯齿=爆料凭证；灰=不可信/无货定格 |
| 3 | **实心 vs 空心** | 实心=采信，空心=推定——同一张图上表达「置信度」第二维度 |
| 4 | **竖直参考线** | 灰实线=2026-05-10 京东标价规则转向日；灰虚线=「5/10 起按日期规则采用」适用边界，配顶部小字注释 |
| 5 | **白色圆角标注气泡** | 事件卡：第一行加粗日期+价格，下面小字解释来龙去脉（如「用户确认同日爆料：6999×80%=5599.20」） |
| 6 | **手绘红圈强调** | 关键低点画红椭圆圈 + 红色大字 ¥8999，把视线钉在结论上 |
| 7 | **右上角末次价 + 状态芯片** | 「末次 ¥9,199」+ 黑底白字「无货」/「在售」芯片，一眼知道这机器现在还买不买得到 |
| 8 | **每日数据覆盖条** | 图底一整条按天分格的彩条：蓝=有直接采用记录、绿=仅存疑/补算、灰=无记录——诚实告诉观众「这段空窗是没数据，不是没涨价」 |
| 9 | **轴标签带口径说明** | Y 轴「国补口径价格（元）」、X 轴「日期（北京时间）」，口径直接写在轴上 |
| 10 | **元信息面板** | 标题下方：机型选择器（型号红色高亮）→ 配置/SKU/当前状态 → 「价格记录 184 条（紫色补充 2 条，邻近推定 35 条…）· 国补存疑 194 条 · 未采纳 0 条」，数据质量量化呈现 |

### 双机对比版（第 10~11 分钟）

| # | 设计元素 | 作用 |
| --- | --- | --- |
| 11 | **A/B 双下拉 + 颜色绑定** | A 机=蓝色、B 机=橙色，图例写明「蓝色=A 记录价，橙色=B 记录价」，跨型号对比老款→新款「涨价接力」一目了然 |
| 12 | **时间轴长度选择** | 「全宽·适应窗口 / 展开」——避免早期稀疏数据把近期密摊拉伸变形 |

### 方法论页（暗色插卡，02:45~03:10）

- 深蓝灰渐变背景 + 超大水印字「国补价格」铺底；
- 左侧深色玻璃卡片展示原始记录（月份 / ¥5599.2），右侧巨型算式「÷ 0.8 = ¥69**99**」（变化位高亮白色）；
- 蓝色对话气泡标签「国补前价」、蓝色描边卡片写判定规则「逆算结果若匹配 99/98/49/48 等整数标价」。

### 汇总表（02:15「整数价月度占比」）

- 深色背景 + 白色表格，重点行（2025-08/09 的 96%/95%）整行红底红框框出；
- 表头灰底加粗，`—` 表示无记录，关键数字加粗。

## 四、网页复刻方案

**目标**：单文件静态网页（HTML + CSS + 原生 JS + 本地 echarts.min.js），离线双击可开，复刻以上设计语言。

**技术选型**：
- ECharts 5.5（本地 `echarts.min.js`，不依赖 CDN）：阶梯折线 `step:'end'`、`markPoint` 圆角卡标注、`markLine` 竖直参考线、`custom series` 画每日覆盖条；
- 无构建、无框架；字体用系统微软雅黑，数字用 Arial 粗体；
- 数据为**按视频口播与画面重建的近似锚点数据**（每机型 6~10 个关键点），仅演示图表风格，非原始数据。

**页面结构**：

```
┌ 顶部：标题 + 数据截止 + 免责说明
├ 结论条：4 张涨跌幅卡片（复刻暗色卡风格）
├ 控制面板（白卡）：机型选择器（型号红色高亮）+ 对比机型 + 时间轴长度
│   ├ 配置行：配置 · SKU · 当前状态
│   └ 统计行：价格记录 N 条（紫色补充/邻近推定/灰色不可信）· 国补存疑 · 未采纳
├ 主图（ECharts）：阶梯线 + 来源配色 + 5/10 参考线 + 标注气泡 + 覆盖条
├ 图例说明：多行图例（形状=含义，复刻原版）
├ 暗色方法论区：÷0.8 逆算卡 + 整数价月度占比表（红框高亮行）
└ 页脚：来源与免责
```

**交互**：机型切换 / A-B 对比 / 时间轴缩放 / 悬浮提示（日期+价格+来源类型+备注）。

- `笔记本价格走势仪表盘.html` —— 主页面
- `echarts.min.js` —— 本地图表库
- `视频图表拆解方案.md` —— 本文档
